# Task: Raised Logo Extrusion

Build a square base with the text `KC` extruded upward as a raised relief.

Functional requirements:

- A square base, 60 mm × 60 mm × 2 mm thick.
- The text `KC` stands proud of the base by 1.5 mm.
- Centered on the base's top face.
- The text is rotated 15° counter-clockwise for visual interest.
- Glyph cap height ≈ 20 mm.
- The result is a single connected solid.

The script must `return` a single `Shape`.
