# task14 (imported from cadqueryeval)

Build the following object as a kernelCAD `.kcad.ts` script returning a single Shape.

Use kernelCAD's primitives and boolean operations. Z-up, millimetres, degrees.

## Description

This part is made by revolving a triangle around an axis by 180 degrees.

The triangle is equilateral (30mm per side).

One of the sides of the triangle is positioned orthogonally to the axis of rotation. The corner of the triangle closest to the axis is 30mm away from the axis.

## Constraints

- Bounding box (X, Y, Z, mm): `[120, 60, 25.981]` — gated within ±2 mm or ±5% per axis (whichever is larger).
- Expected component count: 1.
