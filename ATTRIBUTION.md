# kernelCAD Attribution

kernelCAD names itself in the files it writes and on its public viewer pages.
This page lists every place this happens and how to change it. Nothing is
hidden: all of it is visible in the output.

## Attribution in exported files

Each exporter writes one line into the format's own metadata field. Geometry is
never changed.

| Format | Where | Value |
| --- | --- | --- |
| STEP | `FILE_NAME` originating_system (OCCT stays the preprocessor) | `kernelCAD <version> (https://kernelcad.com)` |
| GLB | `asset.generator` | same |
| STL (binary) | 80-byte header | same, plus the export date |
| DXF | first `999` header comment | same, plus the export date |
| URDF, SRDF, SDF, MJCF | XML comment after the XML declaration | `<!-- Generated by kernelCAD <version> (https://kernelcad.com) -->` |

## "Made with kernelCAD" on public pages

The public share page (`/p/<slug>`) and the embeddable viewer
(`/embed/<slug>`, both presentation modes) show a small "Made with kernelCAD"
link in a corner. It links to `https://kernelcad.com/?ref=<surface>` with
`utm_source=kernelcad&utm_medium=<surface>`, so we can see which surface a
visit came from.

## Changing it (self-hosters and forks)

`src/shared/links/attribution.ts` holds the name, homepage, app URL, the
generator string used in exported files, and the tagged links to our own pages.

A fork that keeps the attribution states truthfully that it is built on
kernelCAD, which the [trademark policy](TRADEMARKS.md) allows. A renamed fork
can change or remove the attribution in `attribution.ts`.

## Third-party shapes in examples and cookbook recipes

Some examples and recipes are ports of openly licensed models: their numbers
were measured from the source and re-modelled in kernelCAD. The source files
themselves are not redistributed. Each entry names the source and its license,
and links the provenance file that records the commit, checksum, extraction and
hand edits.
