## Change

The center drive housing previously used the concrete color, so it blended into
the basin. It now has a separate `castIron` control; the scraper arm uses the
existing `structuralSteel` control. Concrete remains assigned to the basin,
rim, feed well and skirt. The source description and both presets name all three
materials.

The existing drive block is raised above the feed well so it is visible in the
preview. The mesh remains 500 triangles under the 2,200-triangle budget; the
envelope changes from 1.07 × 0.74 × 1.07 m to 1.07 × 0.85 × 1.07 m. The render
shows the dark drive separate from the basin.
