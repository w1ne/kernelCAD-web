# Design brief

Refine the existing `water-treatment/vertical-turbine-pump` asset in place.
Keep its catalog ID and overall scale control. Make the vertical turbine pump
head recognizable in the default preview through its long column, raised
discharge head, side nozzle and flange, separate motor pedestal, ribbed drive,
fan cowl, and electrical terminal box. Let the outlet direction rotate through
four cardinal orientations so the geometry changes for scene placement.

Use four material-named color controls for the coated pump steel, structural
steel, stainless discharge and motor finish. Preserve and extend the existing
`weathered` and `highVisibility` presets. The model remains generic low-poly
visualization geometry; it does not establish a vendor pump's dimensions,
rating, flow performance, installation suitability, or physical acceptance.

Source: `catalog/kits/water-treatment/vertical-turbine-pump.kcad.ts`.
Preview: generated by `scripts/renderCatalogPreviews.ts`.
Evidence: source-driven variant renders, generated catalog index, local catalog
page, kit lint, and catalog integration tests.
