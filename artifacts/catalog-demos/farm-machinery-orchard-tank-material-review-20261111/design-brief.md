# Design brief — orchard sprayer tank material control

The existing CC0 orchard air-blast sprayer is a low-poly scene asset. Its source assigns the chemical tank to the painted-steel color control shared with the chassis and operator cab. Keep the geometry, dimensions, existing public controls, preset names, and triangle budget unchanged; give the tank an independent polymer color control and include it in both existing presets.

The default tank finish should read as light, opaque polymer beside the green painted structure. The regression should verify the palette partition, exported GLB colors, existing presets, triangle count, and envelope. The local preview and catalog index should be regenerated from the source. The handoff should show the five-preview audit, before/after tank color, verification, and local-only provenance.

No equipment dimensions, spray performance, safety, or manufacturing acceptance are established by this scene asset.
