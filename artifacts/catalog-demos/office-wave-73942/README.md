# Office asset wave handoff

This bundle demonstrates the local kernelCAD catalog workflow and the generated office kit. The video replays the six captured presentation frames: the kit overview, actual build/check steps, and all 40 generated catalog previews.

## Demo

- [MP4: office assets](office-assets.mp4) — H.264, 1280×720, 24 fps, 24 seconds, approximately 301 KiB.
- [Capture source](capture.mjs) builds the presentation from the committed `catalog/index.json`, serves its generated preview PNGs locally, and captures frames through an existing Chrome CDP session.
- [Presentation source](presentation.html) is regenerated by `capture.mjs`.
- [Capture settings](settings.json) records the browser version, viewport, CDP endpoint, frame hold and fixed helper timeouts.
- Captured frames (`frames/`, not tracked) are the exact PNG inputs used to encode the MP4.
- [Per-asset checks](catalog-checks.log) and [verification notes](verification.md) record local evidence.

## Reproduce

From the repository root, with the existing Chrome CDP endpoint available at `http://127.0.0.1:9222`:

```sh
node artifacts/catalog-demos/office-wave-73942/capture.mjs
ffmpeg -hide_banner -loglevel error -y \
  -framerate 1/4 \
  -i artifacts/catalog-demos/office-wave-73942/frames/frame-%02d.png \
  -vf 'fps=24,format=yuv420p' -c:v libx264 -profile:v high -level 4.0 \
  -crf 24 -movflags +faststart \
  artifacts/catalog-demos/office-wave-73942/office-assets.mp4
```

The capture helper has a 120-second maximum lifetime and a 30-second idle timeout. It creates one temporary tab, closes only that tab, and does not launch or close a browser.
