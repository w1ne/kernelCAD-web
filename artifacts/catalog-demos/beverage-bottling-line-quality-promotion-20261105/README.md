# Beverage bottling line quality promotion

Local catalog quality evidence for the 5 November 2026 round. The work keeps
the 50 existing asset IDs and makes their machinery forms and material choices
readable in the generated previews.

## What changed

Each source retains its overall scale control and now has two to four
material-named color controls used on corresponding components. Across the kit
that is 137 material-named color controls and 100 preset entries. `sanitaryLine`
and `legacyPlant` set coordinated appearance variants. The blend tank has a raised
vessel on legs, jacket band, agitator, manway, sight glass and outlet. The case
packer has an open guarded frame, lift table, carton and six bottle shapes. The
rotary filler has twelve bottle positions around its rotary table.

The [MP4 demo](beverage-bottling-line-quality-promotion.mp4) compares default
previews with renders generated from the actual `sanitaryLine` overrides. Its
captions identify this as local branch behavior; it does not claim a deployed
website or physical acceptance.

## Retained source and invocation

- `promote_assets.py` records the source transformation used for the 50
  existing models. It adds named finishes, presets, object-specific comments
  and focused silhouette details. Its marker makes a replay on already
  promoted sources a no-op.
- `render_kit_previews.py` invokes the catalog preview renderer in five fresh
  groups of ten to bound the OpenCascade runtime.
- `render_preset_variants.ts` uses the catalog's `variantSource` override path
  to render the actual preset values for the three featured assets. It retains
  default and preset PNGs under `evidence/`.
- `make_demo_video.py` assembles those images into the MP4 and saves the source
  slides under `frames/`.

Run from the repository root:

```sh
python artifacts/catalog-demos/beverage-bottling-line-quality-promotion-20261105/promote_assets.py
python artifacts/catalog-demos/beverage-bottling-line-quality-promotion-20261105/render_kit_previews.py
npx tsx scripts/buildAssetCatalog.ts
npx tsx artifacts/catalog-demos/beverage-bottling-line-quality-promotion-20261105/render_preset_variants.ts
python artifacts/catalog-demos/beverage-bottling-line-quality-promotion-20261105/make_demo_video.py
```

The preview render setting is the source `triangleBudget`, low-poly GLB export,
and the existing software 3/4-view renderer. Preset comparison images use the
catalog row's `sanitaryLine` values and the same low-poly budget. The default
images and selected preset renders are retained in `evidence/` for review.

## Verification

- Kit quality gate: 50/50 assets pass; 2.74 material color controls per asset
  on average (range 2–4).
- Global quality gate: 1,704/2,390 assets pass (71.30%); 686 remain thin
  (28.70%), up from 1,654/2,390 before this round.
- Preview review: `beverage-blend-tank.png`, `bottle-case-packer.png`, and
  `rotary-filler.png` were opened and read as those machines in color.
- Preview paths are regenerated by `scripts/buildAssetCatalog.ts` after the
  render; integration checks also compare source hashes and preview presence.
- The local static page builder emitted 2,390 pages; the generated beverage
  blend tank page, both preset labels, and the kit hub were checked under
  `/tmp/kernelcad-beverage-catalog-pages-20261105/`; all 50 kit page-preview
  pairs are present. This is a local page check, not hosted-page verification.
- `npx eslint catalog/kits/beverage-bottling-line/`: passed.
- `npx vitest run tests/integration/catalog/`: 4 files and 15 tests passed,
  including the full-catalog source hash, parameter, preview, triangle-budget,
  export, and index checks.
- The private dated competitor comparison is retained in
  `kernelCAD-private/docs/competitors/2026-11-05-beverage-bottling-line-quality.md`.

This feature branch has not been deployed; no hosted-page or hardware-acceptance
claim is made.
