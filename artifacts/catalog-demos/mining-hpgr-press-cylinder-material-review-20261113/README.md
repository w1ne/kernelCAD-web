## Change

The four press-cylinder barrels of `mining/high-pressure-grinding-rolls` used the
same chrome constant as the piston rods, so each cylinder rendered as one bright
bar. The barrels now use the existing `structuralSteel` control. The piston
rods, roll shafts, cardan shafts and tie bolts keep chrome. The control label
and the description now name cylinder barrels. All three presets
(`weathered`, `highVisibility`, `bluePlant`) already set `structuralSteel`, so
the barrels follow each preset without new keys.

Geometry is unchanged: 5,142 triangles under the 5,800 budget.
