# v0.4-rc4 Sketch Revolve Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `Sketch.revolve()` so `path()...close().revolve()` produces a 360° solid of revolution around the Z axis from any 2D profile.

**Architecture:** `Sketch.revolve()` registers a `revolve` FeatureRecord with `inputs.sketch` referencing the upstream sketch (parallel to `Sketch.extrude(d)`). The lowerer's existing `revolve` arm gains a `profileKind === 'sketch'` branch, validates the profile (x≥0, non-empty), then calls a new `OcctBackend.revolveFromSketch(sketch)` factory that lifts the sketch's drawing onto the XZ plane and revolves it around `[0,0,1]` (full turn — Replicad's only supported mode). Existing `revolveRect` continues to work unchanged via the same dispatch.

**Tech Stack:** TypeScript, Replicad (OpenCascade WASM), Vitest, Node 20 ESM.

```typescript
  /**
   * Revolve the sketch 360° around the Z axis. The path coordinates are
   * interpreted as `(radial-X, axial-Z)` — first coord = distance from axis,
   * second coord = height along axis. Profile must stay on x ≥ 0.
   *
   * Returns a `Shape` (3D solid). Validation (axis-cross, empty profile)
   * happens at lowering time and surfaces as `feature.revolve.*` diagnostics.
   */
  revolve(): Shape {
    return this.session.createShape({
      kind: 'revolve',
      inputs: {
        sketch: { kind: 'feature', id: this.id },
      },
      params: {
        profileKind: { expression: "'sketch'", unit: 'unitless', evaluated: 0 },
      },
    });
  }
```

```typescript
  /**
   * Revolve a sketch-tagged OcctBackend 360° around the Z axis. The sketch's
   * 2D drawing is lifted onto the XZ plane (so the path's first coord is
   * radial-X, second coord is axial-Z) and revolved around `[0,0,1]`.
   *
   * The returned `OcctBackend` is a normal 3D solid with no `kind` tag.
   *
   * @throws {Error} If `sketch.kind !== 'sketch'` or `sketch._drawing` is null.
   * @throws {Error} If Replicad rejects the geometry (e.g. self-intersecting
   *   profile). Caller must catch and map to a diagnostic.
   */
  static revolveFromSketch(sketch: OcctBackend): OcctBackend {
    if (sketch.kind !== 'sketch' || !sketch._drawing) {
      throw new Error('OcctBackend.revolveFromSketch: input is not a sketch.');
    }
    const lifted = sketch._drawing.sketchOnPlane('XZ');
    const single = lifted as unknown as {
      revolve: (axis?: [number, number, number]) => ReplicadShape3D;
    };
    return new OcctBackend(single.revolve([0, 0, 1]));
  }
```
