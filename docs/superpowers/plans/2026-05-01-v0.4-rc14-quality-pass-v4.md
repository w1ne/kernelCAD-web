## Subagent dispatch protocol

Per `superpowers:subagent-driven-development`, each task gets:
1. Scene-setting context (rc.14 status, predecessors landed).
2. The relevant spec component verbatim (so the subagent doesn't read the spec file).
3. Discipline rules: no competitor refs in committed files, no Claude/AI in commit messages, capture lineage in memory before stripping (per the new Step 0 rule).
4. Status report format (DONE / DONE_WITH_CONCERNS / NEEDS_CONTEXT / BLOCKED).

After each task: quick diff verification by the controller, then dispatch next.
