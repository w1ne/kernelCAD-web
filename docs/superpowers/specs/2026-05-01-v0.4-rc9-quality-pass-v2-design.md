# v0.4-rc9 Quality Pass v2 — Design

**Date:** 2026-05-01
**Milestone:** v0.13.0-rc.9 (NORTHSTAR roadmap step in v0.4-rc trajectory: close all rc.8 review findings + remaining rc.7 deferred items)

## Why

The rc.8 quality review found no Critical issues but 7 Important findings, with one (`EDGE_QUERY_KEYS` quadruplication) materially worse than rc.7 because rc.8's `list_api` added a fourth copy of the key list. Compound-drift risk is now real: every rc that touches queries multiplies the chance one site silently disagrees with another. Plus the four rc.7-deferred items (I-4 errorCode asymmetry, I-5 listFeatures gap, I-6 `Shape.lower()` perf, I-7 cross-realm cleanup) remain open.

rc.9 is a quality pass — same shape as rc.7. No new geometric features. Closes 11 findings across review and deferred lists. New geometric work (loft / closed-rail sweep / 3D paths) resumes in rc.10.

## Scope (12 items, all in)

### Drift protection (foundation — touch first)

**1. Single source of truth for `EDGE_QUERY_KEYS` / `FACE_QUERY_KEYS`.**
Currently duplicated across `src/backends/occt/edgeSelection.ts`, `src/capture/captureSession.ts`, and `src/mcp/tools/listApi.ts`. Extract to `src/backends/occt/queryKeys.ts`. Add a `keyof EdgeQuery` / `keyof FaceQuery` type-level test that fails at compile time if a key is added to the type without the array, OR vice versa.

**2. `list_api` drift sentinel.**
A test that builds the runtime context with `createApi(ctx)` and asserts `Object.keys(api).sort()` matches `GLOBALS.map(g => g.name).sort()`. Same for `Shape.prototype` method names against `SHAPE_METHODS`. Future API additions that miss `listApi.ts` fail this test.

### Diagnostic specificity (rc.8 #4 + rc.7 I-4 + I-5)

**3. Split `feature.sweep.failed` into 3 specific codes.**
- `feature.sweep.profile-too-large` — radius-of-curvature mismatch (heuristic from OCCT error message)
- `feature.sweep.spine-self-intersection` — sharp-corner spine detection
- `feature.sweep.multi-face-profile` — Sketches plural case (#3 from review)

The discriminator runs in `OcctBackend.sweepFromSketch` BEFORE the OCCT call: a multi-face profile is detected via `'face' in lifted` runtime check; OCCT-thrown errors are pattern-matched on message substring (e.g. "self-intersection" / "curvature" → specific code; otherwise fall back to generic `feature.sweep.failed`).

**4. `errorCode` in MCP tool lowering-error path.**
Currently MCP tools set `errorCode` only on `runScript` catch. When `engine.run()` produces error diagnostics, the tools return `{ ok: false, error: <message> }` with no structured code. Plumb `errorCode` through: pick the first error diagnostic's `code` and set it on the tool output. Affects 7 MCP tools (`getShapeInfo`, `listFeatures`, `listTopology`, `getEdgesOf`, `listEdges`, `listFaces`, `listFaceLabels`).

**5. `listFeatures` error reporting.**
Currently the catch path returns `{ features: [] }` with no error or errorCode. Update output type with `error?: string; errorCode?: string` and emit them.

### Robustness (rc.8 #5 + rc.7 I-6, I-7)

**6. Rail length soft cap.**
Add `if (rail.length > 5000)` check in the sweep lowerer arm, emitting `feature.sweep.invalid-rail` with hint to reduce `pointsPerTurn`. Threshold based on: `helix({turns: 100, pointsPerTurn: 32})` = ~3200 points (legitimate), `pointsPerTurn: 200, turns: 50` = 10000 points (likely error). 5000 covers any realistic helix and cuts off the runaway case.

**7. `Shape.lower()` lazy cache.**
Currently every call re-runs `RecomputeEngine.run()`. Cache the lowered backend per `Shape` instance, invalidating only if the session's record list grew (new feature added downstream of this shape). Implementation: store `_loweredBackend?: OcctBackend; _loweredAtRecordCount?: number` on `Shape`; check before recompute. Trade-off: doesn't catch upstream record changes (rare in practice — agents typically build linearly). Acceptable for rc.9; revisit in rc.11+ if telemetry shows agent patterns that invalidate.

**8. Cross-realm `KernelError` cleanup.**
The `isKernelError` structural fallback covers a vm-sandbox scenario that doesn't exist (we don't inject `KernelError` into the sandbox). Drop the structural branch, keep only `instanceof` check. Add a comment explaining the constraint: "tighten when KernelError is injected into the sandbox API surface (rc.10+)".

### Test coverage gaps (rc.8 #6, #7)

**9. `helix()` `startAngle` parameter test.**
One unit test asserting `helix({ ..., startAngle: Math.PI / 2 })[0]` is `(0, radius, 0)` within tolerance. Closes the API-surface-without-regression-guard gap.

**10. Sweep bounding-box assertions.**
Pipe test (`tests/unit/backends/occt/sweepFromSketch.test.ts`) currently verifies volume = 200 but not the swept solid's spatial extent. Add `expect(swept.boundingBox()).toEqual({ min: [-1,-1,0], max: [1,1,50] })` (with tolerance). Catches the regression class where OCCT returns a valid-but-wrong shape (axis-rotated, wrong origin, etc).

### Naming consistency (rc.8 N-8)

**11. `Vec3` / `RailPoint` unification.**
`Vec3` exists in `src/intent/types.ts` AND duplicated in `src/backends/occt/edgeQueries.ts`. `RailPoint` (in `helix.ts`) is a third alias. Pick one — `Vec3` from `intent/types.ts` — and remove the duplicates. `RailPoint` in `helix.ts` becomes a re-export or just `Vec3`. `Sketch.sweep(rail: Vec3[], ...)` uses the imported type.

### Bonus — `OcctBackend` "from sketch" duplication

**12. (Optional) Extract `liftSketchToFace` helper.**
`extrudeFromSketch`, `revolveFromSketch`, `sweepFromSketch` all do `sketch._drawing.sketchOnPlane(plane)` then cast. Factor out `private static liftSketchToFace(sketch, plane): Face` that includes the multi-face check from #3. The existing 3 factories call the helper. Reduces 3-place duplication to 1, and the multi-face guard is uniform.

### Diagnostic discrimination logic for sweep

In `OcctBackend.sweepFromSketch`, after `lifted = sketch._drawing.sketchOnPlane('XY')`:

```typescript
// Multi-face profile detection (#3) — Sketches plural case
if (!('face' in lifted)) {
  throw new Error('SWEEP_MULTI_FACE_PROFILE: profile drawing produces multiple faces; sweep accepts a single closed loop');
}
```

In the lowerer's sweep arm, the catch block matches the error message:

```typescript
} catch (e) {
  const msg = e instanceof Error ? e.message : String(e);
  let code: string;
  if (msg.startsWith('SWEEP_MULTI_FACE_PROFILE:')) {
    code = 'feature.sweep.multi-face-profile';
  } else if (/curvature|too small|profile.*radius/i.test(msg)) {
    code = 'feature.sweep.profile-too-large';
  } else if (/self.intersect|self-intersection/i.test(msg)) {
    code = 'feature.sweep.spine-self-intersection';
  } else {
    code = 'feature.sweep.failed';
  }
  diagnostics.push({ ... code ... });
  return { ... };
}
```

The string-match approach is honest about the brittleness — Replicad's exact error wording could change. The fallback `feature.sweep.failed` ensures unmatched cases still surface a (less specific) diagnostic. New hint table entries spell out the recovery action per code.

### `Shape.lower()` cache

```typescript
class Shape {
  private _loweredBackend?: OcctBackend;
  private _loweredAtRecordCount?: number;

  async lower(): Promise<OcctBackend> {
    const records = this.session.getRecords();
    if (this._loweredBackend && this._loweredAtRecordCount === records.length) {
      return this._loweredBackend;
    }
    // ... existing lowering code
    this._loweredBackend = backend;
    this._loweredAtRecordCount = records.length;
    return backend;
  }
}
```

Invalidation: by record count growth. Records are append-only in the current capture model (no edits during capture), so length growth is the only signal we need. If a future rc adds in-place edits, the cache invalidation widens.

## Acceptance criteria

- All ~22 new tests pass.
- Existing 652 tests stay green.
- `EDGE_QUERY_KEYS` and `FACE_QUERY_KEYS` are imported from a single source by all 3+ consumers; `keyof` test guards drift.
- `list_api` drift sentinel runs in CI; future API additions that miss it fail.
- 3 new sweep diagnostic codes have `whyDidThisFail` hints; old `feature.sweep.failed` becomes documented fallback.
- `Shape.lower()` cache reduces multi-`selectEdges` script lowering count from N to 1.
- `listFeatures` error path emits structured `errorCode`.
- `Vec3` is the canonical name; `RailPoint` either re-exports or disappears.
- PR merges via `qc`. Tag `v0.13.0-rc.9` pushed.
- Live verification: `kcad evaluate --json` on existing fixtures (pipe, spring, washer) still produces valid output (no regression).
