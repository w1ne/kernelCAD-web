# v0.4-rc8 Sketch Sweep + Bundled Quality Fixes — Design

**Date:** 2026-05-01
**Milestone:** v0.13.0-rc.8 (NORTHSTAR roadmap step in v0.4-rc trajectory: sketch sweep + bundled rc.7 review follow-ups)

## Why

Sketch sweep is the largest geometric unlock left in the v0.4-rc trajectory after revolve. With sweep, agents can build pipes, threads, springs, helical gears, hoses, cable runs, twisted rails, and any extrusion along an arbitrary 3D path — an entire class of parts that the existing line+arc+revolve vocabulary cannot reach. The kernel (Replicad) exposes `genericSweep(profileWire, spineWire, config)` already; rc.8 surfaces it through a stable agent-friendly TypeScript API.

Bundled with sweep: two follow-ups from the rc.7 quality review that are cheap to ship now and have outsized agent-first leverage.

- **I-1** (`pickFace` namespace bug): currently a face-feature query mismatch emits `feature.edge-feature.no-edges-match` — wrong namespace. Agents pattern-matching `feature.face-feature.*` to handle face errors miss this code. 15-minute fix.
- **I-3** (MCP API discoverability): `selectEdges`, `selectEdge`, `Shape.lower()`, and `EdgeQuery` / `FaceQuery` key sets shipped in rc.7 but no MCP tool advertises them. Agents reading the kernel via MCP today have to read source code to discover the round-trip flow. New tool `list_api` closes the gap.

## Scope

**Primary feature:** sketch sweep (`Sketch.sweep(rail, opts?)`)

**Bundled fixes:** I-1 namespace + I-3 API discoverability

**Out of scope (deferred):**
- Closed-rail sweep (torus-like) — rc.9
- Variable-profile loft — separate feature kind
- `auxiliarySpine` / `withContact` / custom transition modes — power-user options; defer until tests demand them
- 3D path builder (`path3d()`) — agents use raw 3D polylines or the helix builder for now
- Other rc.7 review findings (I-2, I-4..7) — covered in rc.9 quality pass

## API

### Core sweep

```typescript
// Pipe — closed profile + open straight rail
const profile = path()
  .moveTo(-1, -1).lineTo(1, -1).lineTo(1, 1).lineTo(-1, 1)
  .close();
return profile.sweep([[0, 0, 0], [0, 0, 50]]);

// L-bend pipe — planar 3D rail with a corner
return profile.sweep([[0, 0, 0], [0, 0, 30], [30, 0, 30]]);

// Spring — helical rail, frenet frame so profile rotates with curvature
const railPoints = helix({ radius: 10, pitch: 5, turns: 4 });
return profile.sweep(railPoints, { frenet: true });

// Twisted column — frenet on a curved rail produces twist
return profile.sweep(railPoints, { frenet: true });
```

### `Sketch.sweep(rail, opts?)` signature

```typescript
type RailPoint = [number, number, number];

interface SweepOptions {
  /**
   * Use Frenet frame for profile orientation along the rail.
   * - `false` (default): profile keeps a fixed world-up vector — best for
   *   straight pipes, planar polyline rails, and L-bends.
   * - `true`: profile rotates with the rail's tangent + curvature — needed
   *   for helices, twisted rails, and any non-planar curve where the agent
   *   wants the profile to track the rail.
   */
  frenet?: boolean;
}

class Sketch {
  sweep(rail: RailPoint[], opts?: SweepOptions): Shape;
}
```

### `helix({ radius, pitch, turns, ... })` builder

```typescript
interface HelixOptions {
  radius: number;          // distance from axis (mm)
  pitch: number;           // axial distance per full turn (mm)
  turns: number;           // number of complete revolutions
  axis?: 'X' | 'Y' | 'Z';  // default 'Z'
  pointsPerTurn?: number;  // sample resolution; default 32
  startAngle?: number;     // radians; default 0
}

function helix(opts: HelixOptions): RailPoint[];
```

The function returns a polyline approximating the helix curve. `pointsPerTurn` controls smoothness — 32 is a reasonable default for visual quality at typical CAD scales; agents can crank it up for fine threads.

Math: for axis = 'Z', point at parameter `t` (0 ≤ t ≤ turns) is:
```
x = radius * cos(2π·t + startAngle)
y = radius * sin(2π·t + startAngle)
z = pitch · t
```

### Validation

- Rail must have ≥ 2 points → otherwise `feature.sweep.invalid-rail`
- Rail points must be 3-element tuples of finite numbers → otherwise `feature.sweep.invalid-rail`
- Profile must be a closed Sketch (already enforced by the path builder type system — sketch only exists post-`.close()`)
- Replicad-thrown errors during sweep construction (self-intersection, degenerate spine) → caught and re-emitted as `feature.sweep.failed`

### MCP discoverability — `list_api` tool

```typescript
list_api(args: {}): {
  globals: Array<{
    name: string;             // e.g. 'box', 'path', 'selectEdges', 'helix'
    description: string;
    signature: string;        // human-readable signature
  }>;
  shapeMethods: Array<{
    name: string;             // e.g. 'fillet', 'sweep', 'lower'
    description: string;
    signature: string;
  }>;
  edgeQueryKeys: string[];    // ['atZ', 'atX', 'parallel', 'convex', ...]
  faceQueryKeys: string[];    // ['atZ', 'parallelTo', 'inPlane', ...]
}
```

This is the missing half of rc.7's C4. Agents calling `list_api` see the entire script-runtime surface and can compose `selectEdges` / `Shape.lower()` / arc methods / sweep without reading source. Total MCP surface: 12 → 13.

## Architecture

### Capture layer (`src/capture/sketch.ts`)

`Sketch.sweep(rail, opts?)` registers a new feature record:

```typescript
sweep(rail: RailPoint[], opts: SweepOptions = {}): Shape {
  return this.session.createShape({
    kind: 'sweep',
    inputs: {
      sketch: { kind: 'feature', id: this.id },
    },
    params: {
      profileKind: { expression: "'sketch'", unit: 'unitless', evaluated: 0 },
      frenet: { expression: String(opts.frenet ?? false), unit: 'unitless', evaluated: opts.frenet ? 1 : 0 },
    },
    metadata: { rail },
  });
}
```

### `helix()` global (`src/modules/helix.ts` — new file)

Single pure function. No session dependency — returns a `[number, number, number][]` array. Registered as a script-runtime global in `src/modules/api.ts`.

### Backend (`src/backends/occt/occtBackend.ts`)

New static factory:

```typescript
static sweepFromSketch(
  sketch: OcctBackend,         // sketch-tagged backend (closed profile)
  rail: [number, number, number][],
  opts: { frenet?: boolean } = {},
): OcctBackend {
  if (sketch.kind !== 'sketch' || !sketch._drawing) {
    throw new Error('OcctBackend.sweepFromSketch: input is not a sketch.');
  }
  if (rail.length < 2) {
    throw new Error('sweep: rail needs at least 2 points');
  }
  // Build the spine wire from rail points using replicad's makePolyline / makeWire helpers.
  const spineWire = buildPolylineWire(rail);
  // Convert the sketch drawing to a wire (outer boundary).
  const profileWire = (sketch._drawing.sketchOnPlane('XY') as unknown as { face?: () => { outerWire: () => unknown } }).face?.()?.outerWire?.();
  // ... call replicad.genericSweep(profileWire, spineWire, { frenet: opts.frenet ?? false })
  // Returns a Shape3D.
}
```

(The exact Replicad call shape requires verification during implementation — `genericSweep` takes a `Wire` profile, not a `Sketch`. The sketch drawing's outer-wire-on-plane is the most direct path; alternatives include using `sweepSketch` on the rail-as-sketch with a function that returns the profile sketch.)

### Lowerer (`src/backends/occt/occtLowerer.ts`)

New `'sweep'` arm parallel to `'extrude'` and `'revolve'`:

```typescript
case 'sweep': {
  const profileKind = String(r.params.profileKind.expression).replace(/'/g, '');
  if (profileKind === 'sketch') {
    const sketchInput = inputs.byKey.sketch as OcctBackend | undefined;
    if (!sketchInput) {
      // feature.sweep.bad-sketch diagnostic
      return { ... };
    }
    const rail = (r.metadata as { rail?: unknown }).rail;
    if (!Array.isArray(rail) || rail.length < 2) {
      // feature.sweep.invalid-rail diagnostic
      return { ... };
    }
    // Validate every entry is [number, number, number]
    for (const p of rail) {
      if (!Array.isArray(p) || p.length !== 3 || !p.every(n => typeof n === 'number' && Number.isFinite(n))) {
        // feature.sweep.invalid-rail diagnostic
        return { ... };
      }
    }
    const frenet = r.params.frenet?.evaluated > 0.5;
    try {
      shape = OcctBackend.sweepFromSketch(sketchInput, rail as [number, number, number][], { frenet });
    } catch (e) {
      // feature.sweep.failed diagnostic
      return { ... };
    }
  } else {
    // unsupported-profile
  }
  break;
}
```

### Diagnostic codes (3 new)

| Code | When | Hint |
|---|---|---|
| `feature.sweep.invalid-rail` | Rail < 2 points or contains non-finite/non-3-tuple entries | "Sweep rail needs at least 2 points, each a `[x, y, z]` tuple of finite numbers. For helical rails, use `helix({radius, pitch, turns})`." |
| `feature.sweep.failed` | Replicad rejects the sweep (self-intersecting profile, degenerate spine, etc.) | "OCCT could not sweep the profile along the rail. Common causes: profile larger than the rail's tightest curvature radius, rail with sharp corners that cause self-intersection, or non-planar profile. Try a smaller profile or smoother rail." |
| `feature.sweep.bad-sketch` | sweep with profile='sketch' has no sketch input | "sweep with profile='sketch' requires a sketch input. This usually means the upstream sketch failed to lower — check its diagnostics first." |

### Bundled — I-3 fix (`list_api` MCP tool)

New file `src/mcp/tools/listApi.ts`. Returns the script-runtime surface as static data — no sandbox introspection needed (the API shape is known from `KernelCadApi` interface + `Shape` class definition).

The static data lives in a hand-curated list inside `listApi.ts`; agents reading via MCP get the canonical list. When new APIs land in future rcs, the list is updated alongside the API itself (an enforced step in the rc plan template).

Registered in `src/mcp/server.ts`:

```typescript
{
  name: 'list_api',
  description: 'List the kernelCAD script-runtime surface: global functions (box, path, selectEdges, helix, etc), Shape methods (fillet, sweep, lower, etc), and EdgeQuery/FaceQuery key sets. Use this to discover what is callable from a .kcad.ts script.',
  inputSchema: { type: 'object' as const, properties: {} },
}
```

## Risks

- **Replicad's `genericSweep` profile-wire extraction:** the cleanest path from a Drawing to a Wire is via `sketchOnPlane('XY').face().outerWire()`, but the exact API shape needs verification. If the chain breaks, fall back to building the spine wire and using `sweepSketch` on it (rail-as-sketch with a function returning the profile).
- **Frenet frame at sharp corners:** for a polyline rail with 90° corners, Frenet frame is undefined at the corner. With `frenet: false` (default), Replicad uses a fixed up-vector and produces a clean swept volume. With `frenet: true` on a corner, behavior is implementation-defined; test 6 (L-bend) explicitly uses default `frenet: false`.
- **Helix sample resolution:** `pointsPerTurn: 32` is a polyline approximation, not a true spline. For tight thread profiles, agents may need higher resolution (`pointsPerTurn: 128+`). Documented in the `helix` JSDoc.
