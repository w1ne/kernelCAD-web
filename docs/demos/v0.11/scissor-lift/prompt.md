# Build an animated two-stage scissor lift hero

Create a compact industrial scissor-lift mechanism for the kernelCAD landing page. It should read as a real pinned linkage: base guide rails, two stages of crossed arms, center pivots, sliding roller pivots, visible through-pins, washers/spacers, an upper work platform, and a short actuator that explains why the linkage opens.

The hero animation must show the linkage moving open and closed. Do not only rotate a static object.
