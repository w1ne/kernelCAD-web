# Manufacturing evidence skills demo

This packet shows the workflow added by the `manufacturing-readiness` and
`design-trade-study` skills. It preserves failures, exact source identities,
computed values, model limitations, and the external-action approval gate.

## What happened

1. The existing drafting example in `mounting-plate-stale-example.kcad.ts` was
   evaluated as a negative control. It failed with `query.empty` on its fillet
   selector. The raw result is `evaluate-stale-example.json`.
2. `mounting-plate.kcad.ts` replaced the stale edge query with canonical
   `holes()` and `hole()` operations. The hosted OCCT build passed with no
   diagnostics. Its source SHA-256 is
   `f32440a37c965325ceecc39623658484f82bc09972dea152f2637196b9e96652`.
3. The 4, 8, and 12 mm variants were evaluated on one basis: aluminium density
   2700 kg/m³; Bambu A1 mini FDM checks; two-setup CNC checks from +Z and -Z;
   and a 100 N cantilever-style load study.
4. All variants passed build, FDM, and CNC checks. The structural rows remain
   `WARN` because the in-process voxel solver returned `meshTrusted: false`.
5. With illustrative weights of 35% mass, 40% estimated safety factor, and 25%
   estimated displacement, 12 mm ranked first at 0.650, followed by 8 mm at
   0.554 and 4 mm at 0.350. First place did not change under the tested ±20%
   weight perturbations.

This is a recommendation within the tested set. It is not an optimum and it is
not a manufacturing release. No project overwrite, export, supplier quote,
print, order, or external transfer occurred.

## Evidence files

- `authenticated-evidence.json` — revision-bound values from the connected,
  authenticated KernelCAD MCP tools.
- `trade-study.json` — normalization, scores, ranking, sensitivity, and the
  cheapest discriminating test.
- `invocations.json` — exact tool names and arguments, with source-file refs.
- `evaluate.json`, `dfm-baseline.json`, `mass-baseline.json` — raw public MCP
  results for the shared 8 mm baseline.
- `evaluate-stale-example.json` — raw failed negative-control result.
- `render-*.png` — authenticated deterministic render outputs with checksums in
  `authenticated-evidence.json`.
- `manufacturing-evidence-demo.mp4` — short evidence walkthrough generated by
  `compose_demo.py`.

## Reproduce

Use the arguments in `invocations.json` with the exact `.kcad.ts` source files.
`call_live_mcp.py` can call the public MCP endpoint for individual tools:

```bash
python3 call_live_mcp.py evaluate_script \
  "$(python3 -c 'import json; print(json.dumps({"code": open("mounting-plate.kcad.ts").read()}))')" \
  reproduced-evaluate.json
```

Anonymous compute has a daily allowance. Use a connected authenticated
KernelCAD tool for the complete matrix when that allowance is exhausted.

Regenerate the video after changing evidence:

```bash
python3 compose_demo.py
```
