# Which faces changed: `diff_geometry` face-level change lists

A 60 × 40 × 5 mm motor-mount plate goes from revision A (two M4 clearance holes,
r = 2 mm) to revision B (holes opened to r = 2.25 mm, plus a 22 mm pilot bore for
a NEMA 17 boss). One call compares the two scripts:

```ts
diff_geometry({ baseFile: 'before.kcad.ts', file: 'after.kcad.ts', render: true })
```

Before this change the result gave the verdict (`topology-changed`), the volume
and face/hole count deltas. It now also lists the faces that changed for each
matched body (`bodies[i].faces`), and `summary.text` describes them in words:

```text
Body '(root)' topology-changed: 1 face added (cylinder r=11 at (30, 20, 2.5)),
4 faces resized (cylinder r=2 -> 2.25 at (10, 20, 2.5); cylinder r=2 -> 2.25 at
(50, 20, 2.5); plane 'bottom' area 2374.87 -> 1988.06 mm² at (30, 20, 0); …1 more),
4 unchanged.
```

| list | entries |
| --- | --- |
| `added` | cylinder r = 11 mm, area 345.575 mm², centre (30, 20, 2.5), axis Z: the pilot bore |
| `modified` | the two hole walls, r 2 → 2.25 (`resized`, matched by geometry); `top` and `bottom` planes, area 2374.87 → 1988.06 mm² (`resized`, matched by lineage, refs `@kc[boolean_3/face/top]` / `@kc[boolean_3/face/bottom]`) |
| `removed` | none |
| `unchangedCount` | 4 (the side planes) |

Hand check: 2400 − 2π·2² = 2374.87 mm² before; 2400 − 2π·2.25² − π·11² = 1988.06 mm²
after.

View the [14-second demonstration](demo.mp4). It shows the two revisions, the
`render: true` overlay (removed material red, common material as a grey ghost; this
edit adds no material, so nothing is green), `summary.text`, and the per-face entries.

## How faces are matched

1. **Lineage.** Each face's HistoryMap entry records the feature that made it and its
   role there (`box_1/top`, a sketch label). A key that occurs exactly once on each side
   pairs the faces whatever their geometry did. A translated box therefore reports six
   moved faces, not six removed and six added.
2. **Exact geometry.** Faces without a usable lineage key (unlabelled hole walls and
   fillet faces, assembly parts whose world-frame copies drop lineage) pair as unchanged
   when they have the same surface type, centroid, area, radius and parallel normal/axis.
3. **Near geometry.** The remaining faces pair greedily by nearest centroid within half
   the body's bbox diagonal, provided the surface type matches and the normal or axis is
   parallel. These are reported as modified: `moved` (same size, different place),
   `resized` (area or radius differs) or `reshaped` (surface type differs).

Unpaired faces are `added` or `removed`. Lists are sorted deterministically and each is
capped at 50 entries, with `truncated` and the true `addedCount` / `removedCount` /
`modifiedCount`.

## Files

- `before.kcad.ts`, `after.kcad.ts`: the two revisions (the sources of truth).
- `demo.ts`: the invocation. It writes `result.json` (verdict, volumes, `faces`,
  `summary`, overlay result) and, with `--render`, `overlay/` (`diff-overlay.kcad.ts`
  and `iso.png`). The BREP sidecars the overlay script imports are regenerated by the
  run and are not committed.
- `renderStills.ts`: iso renders of both revisions in `stills/`, made with the same
  `render_preview` pipeline.
- `composeFrames.py`: builds the four 1280 × 720 frames from the stills and
  `result.json`, then encodes `demo.mp4` with
  `ffmpeg -framerate 1/3.5 -i frame-%d.png -vf "fps=24,format=yuv420p" -c:v libx264`.

## Reproduce

```sh
npm run build:player                     # headless player for render_preview
npx playwright install chromium          # once
npx tsx docs/demos/diff-geometry-faces/demo.ts --render
npx tsx docs/demos/diff-geometry-faces/renderStills.ts
python3 docs/demos/diff-geometry-faces/composeFrames.py
```

## Validation

Local validation only. The tool, the overlay and the stills ran on a development
machine against this repository's kernel and headless player. The demo does not show
the hosted MCP service, a deployed build or a fabricated part. Tests:
`npx vitest run tests/integration/mcp/diffGeometryFaces.test.ts tests/integration/mcp/diffGeometry.test.ts`.
