# Manufacturing showcase walkthrough

`manufacturing-workflow.mp4` is a 37-second illustrated walkthrough of seven
manufacturing examples. It shows local `kernelcad evaluate` and DXF, STEP or
3MF export runs beside publish-preset renders of the same source files. The
generator records the base commit, example-source worktree status, and source
and artifact hashes in `video-evidence.json`.

The annotated still sequence is not a screen recording or a deployed-site
capture. The rendered models and successful exports are digital CAD evidence.
They do not show a CAM toolpath, slicer/G-code run, supplier approval, fabricated
part, physical fit, strength test or production acceptance. The remaining
shop checks are listed per example in
[`examples/manufacturing-showcase/README.md`](../../../examples/manufacturing-showcase/README.md).

To reproduce from the repository root:

```sh
npm run build:cli
npm run build:player
npx tsx docs/demos/manufacturing-showcase/make-demo.mts
```

The renderer uses the repository's bundled static player in an isolated
headless Chromium process. It does not attach to or change an interactive
browser profile. The generator requires `ffmpeg` and `ffprobe` on `PATH`.

The integration tests for these examples are
[`manufacturingShowcaseStepRoundTrip.test.ts`](../../../tests/integration/examples/manufacturingShowcaseStepRoundTrip.test.ts),
[`manufacturingShowcaseVariants.test.ts`](../../../tests/integration/examples/manufacturingShowcaseVariants.test.ts),
[`manufacturingShowcaseControls.test.ts`](../../../tests/integration/examples/manufacturingShowcaseControls.test.ts),
and the process-specific tests beside them. They check parameter edits,
process-gate controls and neutral-file readbacks; the video records only the
commands and files generated by its own local CLI run.
