## Hero artifact

meta-glasses

## Why memorable

- Recognizable in one second: Wayfarer trapezoid silhouette with both Meta camera bumps and the LED indicator render so the front view names itself as Ray-Ban Meta smart glasses on first glance.
- New tool central: every visible feature is built from primitive `path()` extrusions + `cylinder().alongAxis()` + boolean union — a curated demo that the kernelCAD primitive API alone is enough for a real consumer product silhouette.
- Reads at 360°: front view shows the Wayfarer trapezoid + camera bumps + bridge nose-notch; iso/right reveal the chunky frame body depth; top view shows both bumps protruding forward off the front face.

## What's new

A curated gallery entry: an agent reproducing the Ray-Ban Meta Wayfarer front face from primitives + booleans, with the camera bumps and LED recording indicator that distinguish Meta smart glasses from a generic eyewear silhouette. No new tool — the demo is about what the existing authoring API can already build.
