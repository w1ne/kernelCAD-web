# kernelCAD v0.15.0

## Unreleased

- **Cookbook parity for hardware, drive, and joinery.** Seven recipes compose existing primitives: involute spur gear pair (center distance `m(z1+z2)/2`), ISO metric hex bolt/nut (M3–M12 table, helical thread via `helix`+`sweep`), 20×20 B-type T-slot (slot 6) with a corner connector, GT2 timing-belt drive (belt length rounded to a real tooth count), wood dado/rabbet/mortise-and-tenon with fit clearance, swept pipe through 3D waypoints with a bend radius, and named engineering material presets driving mass. Snippets in `cookbook/snippets/`; runnable examples in `examples/cookbook-parity/`.

- **`Sketch.extrude(depth)` accepts a `ParamRef`.** The depth of an extruded path can be a declared param, like `box` / `cylinder` dimensions already could; a number is captured exactly as before.
- **ParamRef across the rest of the sketch surface.** `path().circle(cx, cy, r)` accepts ParamRefs (vertices are captured as `cx + r·cos θ` expressions), `Sketch.reflect` keeps symbolic coordinates and takes a ParamRef `offset` (it used to turn them into 0), and `revolve({ angleDeg })`, `loft({ spacing, planes, startPoint, endPoint })`, `extrudePolygon(points)`, tangency entity coordinates and `helix({ radius, pitch, turns, startAngle })` accept `Editable<number>`. Capture-time checks (`tangentCircle` radius, spline/nurbs/hermite pen and duplicate checks) read the param's current value instead of its placeholder.
- **`sweep(helix(...), { spine: 'helix' })` for threads.** Sweeps along the exact helix (two edges per turn) by screw motion, with the profile placed in the axial plane (x radial, y axial). A 60° ISO V thread builds a BRepCheck-valid solid for M3–M12 within 1e-4 of the analytic swept volume, and later booleans against it stay reliable. Overlapping-turn and axis-crossing profiles fail with `feature.invalid-args`.
- **Tapped holes: `hole` / `holes` `thread: { pitch, modeled?, clearance? }`.** `diameter` becomes the nominal size; the bore is the ISO 68-1 minor diameter (+ clearance); `modeled: true` cuts the right-hand basic groove grown by the clearance, `modeled: false` (default) is the cosmetic thread. A bolt swept with `spine: 'helix'` and a nut seated on a whole pitch keep exactly the clearance between them (`verify({ check: 'dfm' })`). The `iso-metric-bolt-and-nut` recipe now uses both.
- **Countersinks cut a real cone.** The wasm build has no `BRepPrimAPI_MakeCone`, and the old builder swallowed that failure, so a countersunk hole came out as a plain bore. The cone is now a revolved profile widest at the entry face. A hole sub-feature that cannot be built fails the hole with an error diagnostic. New recipe: `countersunk-flat-head-screw` (ISO 10642 heads seated flush).
- **One material vocabulary.** Mass (`arm.part`, `inspect({ of: 'mass' })`, static-hold), FEA, the beam check and `.finish()` resolve through one registry of grades (`mild-steel`, `aluminum-6061`, `pla`, `petg`, `abs`, `nylon`) with `steel` / `aluminum` / `aluminium` / `pet` as aliases. Parts record the canonical grade, and unknown names still fail listing every accepted spelling.
- **Interference probes skip face unification.** `detectInterferences` and the DFM clearance probe measure a volume-only common; replicad's `intersect` spent minutes unifying faces on threaded parts. A probe OCCT cannot complete is reported instead of read as "no clash".
