# Keyboard Shortcuts

kernelCAD provides industry-standard keyboard shortcuts to speed up your modeling workflow.

## General

| Action | Shortcut | Description |
| :--- | :--- | :--- |
| **Undo** | `Ctrl` + `Z` (or `Cmd` + `Z`) | Undo the last action. |
| **Redo** | `Ctrl` + `Shift` + `Z` (or `Cmd` + `Shift` + `Z` / `Cmd` + `Y`) | Redo the previously undone action. |
| **Command Palette** | `Ctrl` + `K` (or `Cmd` + `K`) | Open command palette (Planned). |

## Tools & Operations

These shortcuts activate specific tools or operations. They do not trigger while typing in the code editor or input fields.

| Tool | Shortcut | Description |
| :--- | :--- | :--- |
| **Sketch** | `S` | Enter sketch mode (requires a selected face or plane). |
| **Extrude** | `E` | Open the Extrude dialog for the selected profile. |
| **Revolve** | `R` | Open the Revolve dialog. |
| **Offset Plane** | `P` | Create a new offset plane. |

## Feature Modifiers

| Action | Shortcut | Description |
| :--- | :--- | :--- |
| **Fillet** | `F` | Apply a fillet to selected edges. |
| **Chamfer** | `C` | Apply a chamfer to selected edges. |

## Boolean Operations

| Action | Shortcut | Description |
| :--- | :--- | :--- |
| **Union** | `J` | Join/Union shapes. |
| **Cut** | `X` | Cut/Subtract shapes. |
| **Intersect** | `I` | Intersect shapes. |

## View Control

| Action | Shortcut | Description |
| :--- | :--- | :--- |
| **Reset View** | `Home` | Reset camera to default isometic view (if implemented). |
| **Focus Selection** | `.` (Period) | Focus camera on selected object (if implemented). |

> **Note**: Shortcuts use a "typing guard," so pressing `S` while naming a variable `const shape...` will **not** trigger sketch mode.
