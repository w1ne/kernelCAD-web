Build the LeRobot SO-ARM-100 robot arm.

Use `lib.fromSTEP('parts/SO100_Assembly.step')` to import the pre-assembled
5-DOF arm + gripper from the bundled STEP file under
`examples/robot-arm/so100/parts/`. The file is the upstream LeRobot follower
design — every printed link plate, every servo, every fastener is real
vendor CAD, not hand-authored from primitives.

Wrap the imported arm and a locally-authored desk plate as two parts of an
`assembly('so100')`. The desk plate is a flat `box(280, 240, 8)` translated
just below the arm's base so the arm rests on it cleanly. Return
`scene.solvedModel({})`.

Units: millimetres. Z-up. Authoring rule: vendor components via
`lib.fromSTEP`, scene-specific custom geometry (the desk) via primitives.
