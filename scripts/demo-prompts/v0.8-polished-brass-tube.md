# v0.8 hero — Polished Brass Tube

Build a short, mirror-bright brass tube as a kernelCAD `.kcad.ts` script.

Targets:

- A thin-walled cylindrical tube ~16 mm outer diameter, ~56 mm long, wall ~1.2 mm.
- Built from a `nurbsSurface()` (the v0.7 NURBS primitive), thickened to a wall via `.thicken(1.2)`.
- Dressed with **the new v0.8 `Shape.material({...})` PBR call**: warm brass `baseColor`, `metalness: 1.0`, low `roughness`, and a thin `clearcoat`.

The result should show a moving specular highlight as the camera rotates around it — the visible signature of `MeshPhysicalMaterial` replacing the old `MeshStandardMaterial`.

Return a single `Shape`.
