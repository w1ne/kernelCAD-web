# Build a parametric desktop 3-axis robot arm

Build a desktop 3-axis robot-arm assembly out of generic kernelCAD primitives — a base plate, three articulated link plates (shoulder, elbow, wrist), and a tool-placeholder — connected by revolute joints at the shoulder pivot, elbow, and wrist.

The base plate carries four servo-mount holes on a rectangular pattern around a center pivot hole. Each link plate carries two pivot holes, one at each end, so the next link can be connected at the tip. Joint axes: base yaw is vertical (Z), shoulder/elbow/wrist pitches are about Y. The tool placeholder is a small flat tab with a finger cylinder at one end.

Every dimension is editable: declare 12 `param()`s — base width, base depth, plate thickness, link width, pivot diameter, shoulder/elbow/wrist length, screw spacing X, screw spacing Y, screw diameter, and tool length — and derive the rest via `ParamRef` arithmetic (`screwSpacingX.divide(2)`, `linkWidth.multiply(0.85)` for the wrist taper, etc.). Connector frames at each part use `[baseX.divide(2), baseY.divide(2), plateThickness]` style; joint origins reuse the parent connector's `worldOrigin` so a single `setParamValue('baseX', 90)` reactively re-lowers the base, the connector frame, the connected shoulder placement, and the dependent revolute joint origin in one pass.

Constraints: build using only primitives + holes + assembly primitives + revolute joints available at v0.4.1. Connector axes are simple unit vectors (`[0, 0, 1]`, `[0, 1, 0]`); the kernel normalizes them at lower time. All distances in mm.
