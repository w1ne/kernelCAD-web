# Build a hollow cylinder with a labeled cap

Build a cylinder of radius 10 mm and height 20 mm. Apply a `faceLabels` option to name the top face `cap` using the canonical-alias form `{ cap: 'top' }`. Shell the cylinder by 2 mm through the labeled face using `.shell(2, { face: 'cap' })`, then translate the result 5 mm along the X axis.

The result should be an open-top hollow cylinder, slightly offset from the origin. The focus is on demonstrating the canonical-alias path of `faceLabels` on `cylinder`: declare a label at the construction site, resolve it downstream in shell, then apply a transform.

All dimensions in mm.
