# Convert a CC0 rocket image into a v0.4 constrained-sketch keychain

Use the CC0 Wikimedia Commons `Rocket with boosters icon.svg` as the visual reference, then convert it into a flat, readable rocket keychain that demonstrates the v0.4 constraint vocabulary in one memorable model.

- a symmetric booster-rocket hull with matching left/right body sides and fins
- tangent nose-to-body arcs so the nose reads as a smooth rounded cone
- concentric porthole rings centered on the rocket body
- fins set by an explicit angle constraint
- dimensioned body sections that make the nose, porthole, fin roots, and tail stations easy to inspect
- a small keyring hole that makes the converted icon read as a physical charm

Use the constrained-sketch workflow as the design source, then author the production `.kcad.ts` script with literal numeric geometry from the solved sketch. Current runtime params are symbolic ParamRefs, so do not do arithmetic with ParamRef values. If you introduce params, use them only where the chain accepts them directly, such as thickness, hole radii, or fillet radii.

All dimensions are in mm.
