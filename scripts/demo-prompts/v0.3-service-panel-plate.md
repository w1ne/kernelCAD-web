# Build a parametric service-panel mounting plate

Build a 120 x 80 x 10 mm service-panel mounting plate that demonstrates the v0.3 feature set in one readable model:

- four M5 through holes at the corners for cover screws
- two M6 through mounting holes with 11 mm counterbores, 4 mm deep
- one M4 through grounding stud hole with an 8 mm countersink
- one D-shaped cable pass-through cutout that can be enabled or disabled by a boolean parameter

Use symbolic params for plate dimensions, fastener diameters, counterbore dimensions, countersink diameter, and the optional cable-port gate. Name the created features so their generated refs can be addressed downstream.

All dimensions are in mm.
