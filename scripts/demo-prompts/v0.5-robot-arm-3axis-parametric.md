# Build a parametric desktop 3-axis robot arm

Build a parametric desktop 3-axis robot arm with three revolute joints — base yaw (Z), shoulder pitch (Y), elbow pitch (Y). Make it look like an actual hobby robot arm: visible servos at each joint, output shafts, mounting plates, the mechanical density a 3D-printed kit would have. Apply role colors so parts read at a glance (`servo`, `shaft`, `plate`, `beam`, `frame`, `gear`, `tool`).

Define joint angle parameters as `param('baseYawDeg', ..., { min, max })`, etc. Define geometry parameters for every primary dimension and derive the rest via `ParamRef` arithmetic (`.divide`, `.multiply`, `.add`, `.subtract`, `.negate`).

Declare each link as a part on `assembly()` with explicit connector frames; declare three rotational joints with `assembly.revolute(name, parent, child, { axis, origin })`. Decorative parts (servos, shafts, gears) attach to moving links via `assembly.fixed()` so they ride along under FK.

**Return `arm.solvedModel({ ... })` with the joint-angle ParamRefs passed directly** — no `.evaluated`, no hand-rolled `.rotate(axis, deg, pivot)` chains. The kernel runs forward kinematics on every Studio param edit, so sliders bound to those ParamRefs reactively re-pose the rendered arm.

`solvedModel(...)` returns a `Scene` (multi-body, per-part transforms preserved). The renderer iterates parts directly with their role colors; downstream tools that need a single solid call `scene.toUnion()`, and STEP export uses `scene.toCompound()` for lossless named-bodies output.

Z-up, millimetres, degrees.
