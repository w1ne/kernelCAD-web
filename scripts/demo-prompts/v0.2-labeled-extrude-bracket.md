# Build a labeled mounting bracket with a filleted rim

Build a 60×30×12 mm mounting bracket using `extrudeRect`. Apply a `faceLabels` option to name the top face `rim`, then fillet the rim edges by label name using `.fillet(3, { face: 'rim' })`.

The result should be a compact rectangular extrusion with rounded top edges. The bracket is simple by design — the focus is on demonstrating the `faceLabels` API: declare a label at the extrude site, consume it by name downstream.

All dimensions in mm.
