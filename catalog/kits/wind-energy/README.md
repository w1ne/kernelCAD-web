# Wind energy kit

Fifty original low-poly wind-farm turbine, grid and maintenance props. All sources use millimetres, Z up, base origin at z = 0 and editable `scale` and `color` controls. Audited exports range from 60 to 440 triangles, use one material and remain within their per-asset budgets.

The [wind energy wave demo bundle](../../../artifacts/catalog-demos/wind-energy-wave-20261103/README.md) retains the generator, local audit evidence, rendered previews, page check, capture settings and visually inspected MP4. Local page generation was checked; deployed behavior remains unverified.

## Rebuild and verify

```sh
python3 artifacts/catalog-demos/wind-energy-wave-20261103/generate_wind_assets.py
npx tsx scripts/buildAssetCatalog.ts
npx eslint catalog/
npx vitest run src/kernel/backends/occt/occtResetPoison.test.ts
npx vitest run tests/integration/catalog/
python3 artifacts/catalog-demos/wind-energy-wave-20261103/render_wind_previews.py
npx tsx scripts/buildCatalogPages.ts /tmp/kernelcad-wind-pages
python3 artifacts/catalog-demos/wind-energy-wave-20261103/verify_wind_pages.py /tmp/kernelcad-wind-pages
```
