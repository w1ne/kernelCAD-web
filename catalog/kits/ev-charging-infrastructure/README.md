# EV charging infrastructure kit

Fifty original, generic low-poly props cover AC and DC charging equipment, generic connector forms, cable routing, site electrical cabinets and controls, parking fixtures, canopies, and fleet equipment. Each source is an editable `.kcad.ts` model in millimetres with Z up and a base origin. The `scale` knob ranges from 0.70 to 1.30; `color` sets the single material. Audited exports range from 92 to 388 triangles, under the 2,400-triangle budget.

Every indexed asset has a generated preview path for the homepage asset rail. This branch is not deployed, so public visibility of this kit remains unverified. The [EV charging wave demo bundle](../../../artifacts/catalog-demos/ev-charging-wave-20261103/README.md) retains the generator, settings, audits, local page checks, and visually inspected MP4.
