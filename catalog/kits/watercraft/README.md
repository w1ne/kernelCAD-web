# Watercraft

Original low-poly boats and marine equipment for harbor, lake and coastal
scenes. Watercraft hulls sit on the Z=0 waterline so they can be placed directly
in a scene; compact deck props use the same base origin. Choice knobs select
useful physical variants and color knobs set one-palette export colors.

## License and provenance

Every source is original kernelCAD geometry dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No
downloaded, traced or converted meshes, textures or palettes are used.
