# Telecom infrastructure kit

Fifty-six original low-poly communications-site, rooftop, radio and fiber-network props. All sources use millimetres, Z up, base origin at z = 0 and editable `scale` and `color` controls. Audited exports range from 48 to 476 triangles, use one material and remain within their per-asset budgets.

The [telecom infrastructure wave demo bundle](../../../artifacts/catalog-demos/telecom-infrastructure-wave-20261102/README.md) retains the generator, local audit evidence, rendered previews, page check, capture settings and visually inspected MP4. Local page generation was checked; deployed behavior remains unverified.

## Rebuild and verify

```sh
python3 artifacts/catalog-demos/telecom-infrastructure-wave-20261102/generate_telecom_assets.py
npx tsx scripts/buildAssetCatalog.ts
npx eslint catalog/
npx vitest run tests/integration/catalog/
python3 artifacts/catalog-demos/telecom-infrastructure-wave-20261102/render_telecom_previews.py
npx tsx scripts/buildCatalogPages.ts /tmp/kernelcad-telecom-pages
python3 artifacts/catalog-demos/telecom-infrastructure-wave-20261102/verify_telecom_pages.py /tmp/kernelcad-telecom-pages
```
