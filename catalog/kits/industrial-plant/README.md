# Industrial Plant kit

Low-poly factory and process-plant scene props built from original parametric kernelCAD source. The kit covers vessels, rotating equipment, air handling, electrical gear, material handling and access structures. Assets use millimetres, Z up, real-world scale, base-grounded origins and a shared vertex-coloured palette material.

Each `.kcad.ts` file is the source of truth. Geometry is authored from scratch with kernelCAD primitives and polygon profiles; no downloaded, traced, converted or decimated meshes are used. Every asset is dedicated to the public domain under CC0 1.0.
