# Travel gear

Original low-poly luggage and small travel accessories for hotel, airport and
journey scenes. The modern rolling suitcase is distinct from the existing
vintage steamer trunk; this kit does not repeat the existing hiking backpack.
The public catalog exposes shape choices and color knobs through native
kernelCAD asset metadata.

## License and provenance

Every source is original kernelCAD geometry dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). No
downloaded, traced or converted meshes, textures or palettes are used.
