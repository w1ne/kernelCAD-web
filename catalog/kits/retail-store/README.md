# Retail store kit

The kit retains 48 low-poly fixtures and service props for checkout and payment,
shelving, chilled displays, shopping, stock handling and customer-service
areas. Each existing ID keeps its `scale` knob and now has two to four
material-named color controls plus `cleanStore` and `nightRestock` presets. The
promotion adds 144 material controls and 96 preset entries; the quality gate
passes 48/48 assets (100%). All 48 refreshed
previews are indexed. Geometry now shows a wire cart basket, slatted carry
baskets, ventilated crate stack, framed cooler door with stocked shelves, and a
checkout fascia with cashier display. Sources use millimetres, Z up, and a
floor origin at z = 0. Exports remain within their declared triangle budgets
and use one material per mesh.

The [original retail-store wave bundle](../../../artifacts/catalog-demos/retail-store-wave-20261102/README.md)
preserves initial source evidence. Current preview, index, local-page, test and
demo checks are in the [quality-promotion bundle](../../../artifacts/catalog-demos/retail-store-quality-promotion-20261105/README.md).
The live asset-library route and `/catalog/` were checked on 2026-11-05; this
branch has not been deployed.

## Re-render and verify

```sh
# Run the exact 48-ID command linked below before rebuilding the index.
npx tsx scripts/buildAssetCatalog.ts
python scripts/checkCatalogQuality.py --kit retail-store
npx eslint catalog/kits/retail-store/
npx vitest run tests/integration/catalog/
npx tsx scripts/buildCatalogPages.ts /tmp/kernelcad-retail-store-pages
python3 artifacts/catalog-demos/retail-store-quality-promotion-20261105/verify_retail_store_pages.py /tmp/kernelcad-retail-store-pages
```

The exact preview IDs are in the bundle's [preview-render
invocation](../../../artifacts/catalog-demos/retail-store-quality-promotion-20261105/preview-render-invocation.txt).
The included source-promotion script expects the original thin, single-color
sources; it records this one-time conversion rather than a command to rerun on
the already-promoted kit. The original wave bundle preserves initial asset
creation evidence.
