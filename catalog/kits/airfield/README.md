# Airfield kit

Forty original low-poly aircraft, apron service vehicles and airport fixtures for airfield scenes. Sources are authored in kernelCAD in millimetres, Z up. Each asset keeps its scale control, adds two to four material-specific color controls and the `weathered` and `highVisibility` presets, and has a rendered preview indexed in the catalog. Each remains within its 1,800-triangle budget. These are visualization props, not operational or airworthiness models.

The [airfield wave demo bundle](../../../artifacts/catalog-demos/airfield-wave-20261102/README.md) retains source, capture settings, local verification evidence, generated-page checks and an inspected MP4.

## Quality promotion

The [airfield quality handoff](../../../artifacts/catalog-demos/airfield-quality-promotion-20261105/README.md) records the in-place material controls, presets, cab glazing, ARFF roof ladder and building silhouette refinements, refreshed previews, generated index, local checks, and inspected MP4. No asset IDs were added.

## Rebuild and verify

```sh
python3 artifacts/catalog-demos/airfield-wave-20261102/generate_airfield_assets.py
python3 artifacts/catalog-demos/airfield-quality-promotion-20261105/promote_airfield_quality.py --apply
# Re-render all 40 IDs listed in the promotion bundle's preview-render-invocation.txt.
npx tsx scripts/buildAssetCatalog.ts
npx eslint catalog/kits/airfield/
npx vitest run tests/integration/catalog/
python3 scripts/checkCatalogQuality.py --kit airfield
npx tsx scripts/buildCatalogPages.ts /tmp/kernelcad-airfield-catalog-pages
python3 artifacts/catalog-demos/airfield-quality-promotion-20261105/verify_airfield_pages.py /tmp/kernelcad-airfield-catalog-pages
npx tsx artifacts/catalog-demos/airfield-quality-promotion-20261105/render_airfield_presets.ts
python3 artifacts/catalog-demos/airfield-quality-promotion-20261105/capture_airfield_quality.py
python3 artifacts/catalog-demos/airfield-quality-promotion-20261105/inspect_airfield_quality_video.py
```
