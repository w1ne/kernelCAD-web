# Postal logistics kit

52 original low-poly parcel-processing scene props cover induction, scanning, sortation, parcel handling, route preparation, and dispatch. All sources use millimetres, Z up, a base origin at z = 0, and editable `scale` and `color` controls. Audited exports range from 96 to 240 triangles, use one material, and stay within their per-asset 1,800-triangle budget.

The [postal logistics wave demo bundle](../../../artifacts/catalog-demos/postal-logistics-wave-20261103/README.md) retains the source generator, preview and page checks, integration and lint evidence, the built npm package audit, capture settings, and visually inspected MP4. Local page generation is checked separately from deployed behavior.
