# Water-treatment assets

This 50-asset kit covers intake screening, pumping, chemical dosing, filtration,
clarification, disinfection, process piping, and monitoring. The promotion keeps
the existing asset IDs and scale controls. Each source now exposes two to four
material-named color controls and `weathered` / `highVisibility` presets.
Cylindrical vessels, pumps, valves, and instruments use lofted profiles with
beveled shoulders; concrete basins and screening racks retain their
rectilinear construction. The lamella clarifier has inclined plates and side
supports.

The [quality-promotion bundle](../../../artifacts/catalog-demos/water-treatment-quality-promotion-20261105/README.md)
contains the source promotion script, before/after and preset renders,
verification records, and an inspected MP4. The [original catalog wave
bundle](../../../artifacts/catalog-demos/water-treatment-wave-20261103/README.md)
retains the initial source generator and preview workflow.

These are stylized visualization props. They do not specify flow rates,
treatment performance, pressure capacity, chemical dosing accuracy, process
safety, regulatory compliance, installation suitability, or physical
acceptance.
