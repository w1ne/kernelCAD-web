# Tools & Equipment kit

Low-poly hand tools, power tools and workshop pieces for garage, farm, construction and survival scenes at real-world scale, flat-shaded on one palette material. Modelled in millimetres with Z up and exported as GLB in metres. Each piece has choice knobs for sizes, styles and states, colour knobs for its material zones, and a few presets.
