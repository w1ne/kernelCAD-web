# Recycling facility assets

This kit adds 153 original low-poly scene props covering inbound reception,
material sorting, baling, glass and plastics recovery, organics processing, and
residual management. Each `.kcad.ts` source exposes overall scale and color,
uses one material, declares a triangle budget, and has an indexed rendered
preview.

These are visualization assets. They do not represent equipment specifications,
process performance, operator safety, regulatory compliance, or physical
acceptance. See the [wave demo and verification bundle](../../../artifacts/catalog-demos/recycling-facility-wave-20261103/README.md)
for the generator, commands, audit results, and inspected MP4.
