# Mining and mineral-processing kit

Fifty original low-poly props cover underground equipment, mine-site handling, and representative mineral-processing stages. Each source keeps its editable `scale` input and has two to four material-named color controls for the visible coated steel, structural steel, stainless steel, and rubber parts. The `weathered` and `highVisibility` presets offer distinct equipment palettes. Rotating drums, rollers, sheaves and shafts use faceted loft profiles; frames, chutes, conveyors and vehicles retain their separate named components. The regenerated meshes range from 144 to 600 triangles under their declared 1,800-triangle budgets.

The generated index gives all 50 assets a homepage preview URL. This branch is not deployed, so the updated public page behavior has not been verified after deployment. The [quality promotion demo bundle](../../../artifacts/catalog-demos/mining-quality-promotion-20261105/README.md) retains the source transformation, before and after previews, indexed preset render, verification evidence, and inspected MP4. The [original mining wave bundle](../../../artifacts/catalog-demos/mining-wave-20261103/README.md) retains its initial creation record.
