# Hydroponics kit

52 original low-poly controlled-environment growing props cover greenhouse structures, hydroponic beds, nutrient storage and delivery, filtering, sensing, climate equipment, and crop support. Sources use millimetres, Z up, a base at z=0, and editable `scale` and `color` controls. The indexed meshes range from 128 to 372 triangles with one material and a per-asset budget of 1,800 triangles.

The [hydroponics wave demo bundle](../../../artifacts/catalog-demos/hydroponics-wave-20261103/README.md) retains the generator, preview audit, integration and lint results, local page check, package-boundary audit, capture settings, and inspected MP4. Local pages are checked separately from deployed behavior.
