# Beverage bottling line

This kit covers a small beverage plant from container preparation through
filling, closure, labelling, inspection, case packing, and pallet handling. It
also includes product-preparation and clean-in-place equipment so the assets
can be arranged into a complete factory scene.

Each asset is an original CC0 `.kcad.ts` model in millimetres with editable
overall scale, body colour, and safety-accent colour. The generated low-poly
GLB is constrained by the source file's triangle budget and uses one material.
These are stylized scene props; they do not specify real machine performance,
food-safety compliance, pressure ratings, or installation requirements.

The local source, preview, and audit workflow is shown in the [wave demo and
verification bundle](../../../artifacts/catalog-demos/beverage-bottling-line-wave-20261103/README.md).
