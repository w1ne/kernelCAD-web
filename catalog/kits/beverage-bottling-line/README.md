# Beverage bottling line

This kit covers a small beverage plant from container preparation through
filling, closure, labelling, inspection, case packing, and pallet handling. It
also includes product-preparation and clean-in-place equipment so the assets
can be arranged into a complete factory scene.

Each asset is an original CC0 `.kcad.ts` model in millimetres with editable
overall scale, two to four material-named color controls, and `sanitaryLine` /
`legacyPlant` appearance presets. Depending on the machine, the controls cover
stainless steel, powder-coated steel, food-grade polymer, safety paint,
corrugated board, and glass tint. The generated low-poly GLB is constrained by
the source file's triangle budget and uses one material. These are stylized
scene props; they do not specify real machine performance, food-safety
compliance, pressure ratings, or installation requirements.

The quality promotion retained all 50 asset IDs, replaced the generic finish
controls with 137 material-named color controls, added 100 preset entries, and
refreshed all 50 previews. The [quality
promotion handoff](../../../artifacts/catalog-demos/beverage-bottling-line-quality-promotion-20261105/README.md)
contains the source transformation, preset render command, inspected MP4 and
local verification evidence. The [original wave demo](../../../artifacts/catalog-demos/beverage-bottling-line-wave-20261103/README.md)
records the initial source and preview workflow.
