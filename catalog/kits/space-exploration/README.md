# Space exploration kit

Fifty-two original low-poly lunar habitat, mobility, communication and field-science props. All sources use millimetres, Z up, base origin at z = 0 and editable `scale` and `color` controls. Audited exports range from 60 to 452 triangles, use one material and remain within their per-asset budgets.

The [space exploration wave demo bundle](../../../artifacts/catalog-demos/space-exploration-wave-20261103/README.md) retains the generator, local audit evidence, rendered previews, page check, capture settings and visually inspected MP4. Local page generation was checked; deployed behavior remains unverified.

## Rebuild and verify

```sh
python3 artifacts/catalog-demos/space-exploration-wave-20261103/generate_space_assets.py
npx tsx scripts/buildAssetCatalog.ts
npx eslint catalog/
npx vitest run tests/integration/catalog/
python3 artifacts/catalog-demos/space-exploration-wave-20261103/render_space_previews.py
npx tsx scripts/buildCatalogPages.ts /tmp/kernelcad-space-pages
python3 artifacts/catalog-demos/space-exploration-wave-20261103/verify_space_pages.py /tmp/kernelcad-space-pages
```
