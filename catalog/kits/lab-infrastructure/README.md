# Laboratory Infrastructure kit

Sixty original low-poly room-planning props for laboratory work areas, storage, service distribution, local extraction, cleanroom transitions and cold rooms. Sources use millimetres, Z up and a ground-level base origin. Each asset exposes `scale`, two to six material-named color controls, and at least `cleanroom` / `highVisibility` appearance presets; rebuilt assets add a third preset and a shape option such as sash position, door, flow direction or eyewash. The models are visual scene props, not engineering, safety or compliance specifications.

The [laboratory infrastructure wave demo bundle](../../../artifacts/catalog-demos/lab-infrastructure-wave-20261102/README.md) retains the original source and catalog-workflow capture.

The [quality-promotion demo bundle](../../../artifacts/catalog-demos/lab-infrastructure-quality-promotion-20261105/README.md) shows the refreshed materials, presets, silhouettes, preview renders and local verification.

## Use a catalog asset

Search the catalog for a laboratory fixture, or open a known asset in Studio with `?catalog=lab-infrastructure/<id>`. For example, `?catalog=lab-infrastructure/laboratory-fume-hood` opens the original source with its scale and palette controls.

## Rebuild and verify

The historical [2026-11-02 source wave](../../../artifacts/catalog-demos/lab-infrastructure-wave-20261102/README.md) documents the initial kit build. The [2026-11-05 quality-promotion bundle](../../../artifacts/catalog-demos/lab-infrastructure-quality-promotion-20261105/README.md) records the in-place promotion and its verified commands. It retains the promotion script, rendering settings, before/after evidence, preview review, index audit, lint output and integration results.

The promotion script transforms the source state from the start of that round. To replay it, use a disposable worktree at the round's parent revision, bring in the bundle script, then run the recorded render and index commands there. The verification commands for the finished sources are:

```sh
npx eslint catalog/kits/lab-infrastructure/
npx vitest run tests/integration/catalog/ --maxWorkers=1 --no-file-parallelism
npx tsx artifacts/catalog-demos/lab-infrastructure-quality-promotion-20261105/check_lab_pages.mts
```
